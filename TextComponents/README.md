# Story Generator using a Text Form GUI

### Description

This application generates a story from user input "text".
It does the following:

- Update labels based on user input
- Accept multiple texts in a text fields
  -?MAYBE chnage text color with buttons

- DIsplay the use input in stdin use sysout

### Usage

In order to start the application, ensure that Header, Center, and Footer compile.
javac Header.java Center.java Footer.java

Once you have confirmed that the necessary components work, you may compile and run the Main class.
javac StoryGenerator.java
java StoryGenerator
