# Story Generator using a Text Form GUI

## Input Questions:
- Name an object: (default: book)  
- Favorite color: (default: grey)  
- A big number: (default: 159)  
- Name a place: (default: Stohess District)  
- Type of sound: (default: whispering)  
- Name a character: (default: Levi) 

## Story:
(characterName) woke up alone in the middle of nowhere. He looked to his left and saw a half-decayed wooden sign that read, “20 miles left until (place).”

(characterName) walked through the (color)-tinted, misty forest until he heard (soundType) all around him. He increased his pace, trying not to panic, as footsteps grew louder behind him.

He turned abruptly to check, but found nothing. His worry eased, but before he turned back, a blunt (objectName) hit him from behind.

As he fell to the ground, he saw the figures of (number) creatures standing silently behind the person holding the (objectName).


### Description


This application generates a story from user input "text".
It does the following:

- Update and display labels based on user input

### Usage

In order to start the application, ensure that Header, Center, and Footer compile.
javac Header.java Center.java Footer.java

Once you have confirmed that the necessary components work, you may compile and run the Main class.
javac StoryGenerator.java
java StoryGenerator
